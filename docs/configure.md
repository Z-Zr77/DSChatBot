# 配置说明

所有设置在控制台 **http://127.0.0.1:3070** 里改，不用改文件。

## 第一次要填的

打开控制台 → 左侧「设置」：

| 项目 | 填什么 |
|---|---|
| 主人 QQ | 你自己的 QQ 号（她只认这个号是"主人"，也决定记忆存在哪个文件里） |
| 接口地址 | 例如 `https://api.deepseek.com/v1`（必须带 `/v1`） |
| 模型 | 例如 `deepseek-flash`；点「拉取」可以从服务商列出来选 |
| API Key | 服务商给你的 `sk-` key，留空表示"不改原来那个" |

填完点「保存（API）」，再回聊天窗说话。换的不是同一家供应商时，点「重启桥接」让它重新读配置。

「测试连接」会真的发一句话给模型，能回来说明配置对；报 `invalid api key` 就是 key 不对或被删了。

## 常驻

- **开机自动启动**：设置页「常驻」里勾上并保存。勾了以后系统一启动她就起来了，不用你手动点。
- 关窗口不退出：点右上角 × 只是把窗口藏起来，程序还在托盘里跑（右键托盘图标可以退出）。

## 她的作息和主动消息

设置页「主动性」一组：

| 项目 | 默认 | 说明 |
|---|---|---|
| 每天最多 | 8 次 | 主动找你的上限 |
| 同一人间隔 | 30 分钟 | 两次主动之间的最小间隔 |
| 活跃时间 | 08:00–01:00 | 这段时间之外她不打扰 |
| 开口概率 | 0.7 | 每次"想说话"真正发出来的概率 |

没接 QQ 的时候，主动消息会用 Windows 通知弹出来，点通知直接进聊天窗。

## 语音、看图

- 语音合成（TTS）：供应商选阿里云 CosyVoice / OpenAI 兼容 / Edge-TTS，各有自己的地址、模型、key。
- 看图：默认用大脑模型自己看；大脑不支持图片时，填一个能看图的模型（或百炼 key）走视觉模型。

## 群聊

「群聊」里两个开关：`在群里说话`、`只叫名字才理`。默认只叫名字才回。

## 文件都在哪

| 文件 | 内容 |
|---|---|
| `data\setup.json` | 接口地址、模型、key、QQ 号、功能开关 |
| `data\config.json` | 桥接的语气/生成/语音/主动性等运行配置 |
| `data\chat\config.json` | 聊天窗自己的偏好（字体、置顶、透明度、端口） |
| `data\napcat\` | QQ 内核目录 |

## 换电脑 / 换盘

把整个 `data\` 文件夹拷过去就行：记忆、聊天记录、表情包、人格、配置都在里面。

## 常见改动什么时候生效

- 提示词、语气、主动性：下一条消息生效
- 接口地址 / 模型 / key：点「重启桥接」后生效
- 端口、开机自启、二维码令牌：重启程序后生效
