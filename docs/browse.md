# 她自己上网看东西：现在是什么状态

## 一句话

**现在能真联网了：走阿里云百炼的 `enable_search`（用你已有的 aliyun key，不用另买搜索服务）。**

没有 key 的时候会自动跳过，**绝不拿模型编的当见闻**（2026-11-01 的旧版就是编的，已修）。

关着的时候她不会假装刷到过什么——因为一旦她说"我今天看见有个乐队在街边演出"，
你会以为是真的，其实那是模型自己编的。

## 现在（关着）是什么情况

- 每 2 小时跑一次 `browseTick`，模型按你的兴趣"想象"出 1–3 条见闻，存进 `data/life-seen.jsonl`。
- 这些内容**没有经过任何网页核对**。
- 所以默认关。要开也可以：`config.json` 里 `browse.enabled = true`——但请知道你在开什么。

## 以前的两个 bug（已修）

1. `browse.enabled` 这个勾选框**从来没被代码读过**，关掉了也照跑。现在关了就是关了。
2. 刷到的东西只写进 `life-seen.jsonl`，**没有任何出口**——她看了半天，一个字都没跟你说过。
   现在接了「分享」：刷完挑一条，用她自己的口气跟你说一句（一天最多两次、间隔三小时）。

## 要真联网，缺什么

缺一个**搜索服务**。现在的 `pack/src/net.mjs` 只能"给我一个网址我去抓"，没有搜索引擎。

可选（按接入成本排序）：

| 方案 | 费用 | 说明 |
|---|---|---|
| SearXNG（自建/公共实例） | 免费 | JSON 接口，最省；公共实例可能不稳 |
| Bocha / Serper | 约 ¥0.01/次 | 国内可直连，返回结构化结果 |
| Tavily | 约 $0.008/次 | 给 LLM 用的检索，质量好 |

接上之后要做三件事：

1. 加一个 `search.mjs`：`search(query) → [{title, url, snippet}]`
2. `browsePrompt` 改成"先搜、再挑、只能引用搜索结果里的东西"
3. 打开 `browse.enabled`，把默认兴趣填一份（现在 `interests.json` 只有 228 字节）

## 边界

- 只读：不许登录、不许发帖、不许点表单（提示词里已经写了）
- 同一兴趣一天最多 4 次（`curiosity.DEFAULTS.maxPerDay`）
- 分享出去的话，一天最多 2 次，间隔 ≥ 3 小时（`pack/src/share.mjs`）
