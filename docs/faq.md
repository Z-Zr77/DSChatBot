# 常见问题

## 她说"我连不上模型：key 被服务器拒了"

你填的 API Key 失效了（被删、被重置、或者填错了）。去控制台「设置」→ 大脑（API）→ 粘贴新的 key → 保存 → 点「重启桥接」。保存前可以先点「测试连接」验证。

## 她一直说"卡了一下"

先看控制台「日志」页最后几条：

- `dsh failed: HTTP 401` → key 的问题（见上）
- `dsh failed: fetch failed` / `timeout` → 网络或服务商不通，检查接口地址，或者换个时间再试
- `ws down` → 那是 QQ 内核没连上，跟聊天窗无关

## 装了但打不开聊天窗

浏览器访问 http://127.0.0.1:3210 。打不开就看 `data\chat-port.txt` 里的实际端口（端口被占用时会自动换一个），或者看 `%LOCALAPPDATA%\DSChatBot-main.log`。

## QQ 登录不上 / 一直"待命"

她需要本机的 NapCat 内核。控制台「状态」页：

1. 看「守卫状态」有没有在跑
2. 点「立即换一张」重新出二维码
3. 手机 QQ 切到小号扫码，扫完在手机上点"确认登录"
4. 二维码 100 秒左右会过期，这期间别扫旧的

不接 QQ 也能用：浏览器聊天窗是完整的。

## 她说她动不了电脑

「允许她动电脑」默认是关的。去控制台「设置」勾上，再进工作模式选一个文件夹。她只在这个文件夹里读写，跑命令会弹卡片等你点同意。

## 生图没反应 / 提示不支持

生图和自拍需要一个支持图像接口的模型，光有对话模型不行。控制台「设置」里给生图单独配模型和 key。

## 她不会主动找我

检查三件事：

1. 「主动性」里的「启用」有没有勾
2. 当前时间在不在「活跃开始–活跃结束」之间（默认 08:00–01:00）
3. 「同一人间隔」「每天最多」是不是已经用完了

没接 QQ 时，主动消息以 Windows 通知出现——如果系统里关掉了这个应用的通知权限，就看不见。

## 有新版本怎么看

聊天窗顶部会出现一行「有新版本 vX · 去看看」，点进去就是 Release 页。启动时自动查一次，之后每 6 小时一次。

## 端口被占用

默认 3070（控制台）、3210（聊天窗）、3098（本地通道）。被占用会自动换，实际端口写在 `data\ui-port.txt` 和 `data\chat-port.txt`。

## 我想换电脑

把 `data\` 整个拷过去，装好新版本，覆盖进去就行。记忆、聊天、表情包、配置都在里面。

## 卸载会丢记忆吗

不会自动删。要彻底清掉，见 [privacy.md](privacy.md) 的"怎么彻底删掉"。

## 能不能在手机上看

这一版只做 Windows。手机端暂时不做。
