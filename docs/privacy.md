# 隐私：你的数据在哪、会不会被上传

## 一句话

**没有遥测，没有统计上报，也不会把聊天内容传到我们自己任何服务器**（我们也没有服务器）。所有数据都在你自己这台电脑上。

## 什么东西会离开这台机器

只有一种情况：把话发给**你自己配置的模型服务商**。

- 你填的 baseUrl 是哪个，请求就发到哪个
- 每次带的是：她的人设提示词 + 最近的对话 + 这次要回的内容 + 相关的记忆条目
- key 是你自己的（BYO Key），我们不接触
- 服务商怎么处理，取决于它自己的隐私政策

**没接 QQ 的时候，她把主动消息发到 Windows 通知，这条也不出机器。**

## 本地存了什么（都在 `data\`）

| 内容 | 位置 | 说明 |
|---|---|---|
| 聊天记录 | `data\chat\<QQ>.jsonl` | 明文，可自己删 |
| 记忆 | `data\agent-home\memory\people\<QQ>.json` | 明文 |
| 她自己的状态 | `data\life.json`、`data\state\` | 作息、情绪、精力 |
| 配置和 key | `data\setup.json`、`data\config.json` | key 明文存（本机文件，别把这个文件发给别人） |
| 生成/收到的图 | `data\drawn\`、`data\chat\media\` | |
| 工作模式的改动与审计 | `data\ledger\` | 每条改动的前后哈希 + 命令审计 |
| 备份 | `%USERPROFILE%\DSChatBot-backups` | 打包的上面这些 |

## 网络请求清单（代码里能搜到）

- 你配的模型服务商：对话 / 看图 / 语音 / 生图
- `api.github.com`：启动时查一次有没有新版本（只读公开信息，不发送任何本地数据）
- 你接 QQ 之后：走本机 NapCat 的本地端口（127.0.0.1），不经过我们

除此之外没有别的出站请求；也没有崩溃上报、埋点、统计。

## 怎么彻底删掉

1. 退出程序（托盘右键 → 退出）
2. 删掉安装目录下的 `data\` 文件夹
3. 想连备份一起删：删掉 `%USERPROFILE%\DSChatBot-backups`

卸载程序本身不会自动删 `data\`（这是故意的：重装不该丢记忆）。

## 公开仓库里有什么

GitHub 上的源码和安装包里**不含任何用户数据**：没有聊天记录、没有记忆、没有 key、没有本机路径。发布前做过一遍全仓库扫描（`sk-`、QQ 号、主机路径、真实记忆文本，0 命中）。
