# 五分钟上手

## 1. 装

下载 `DSChatBot-Setup-x.y.z.exe` → 双击 → 选目录（默认 `E:\DSChatBot`）→ 安装。

装完会自动打开**聊天窗**。没打开的话：
- 开始菜单搜 `DSChatBot`；
- 或浏览器打开 <http://127.0.0.1:3210>。

## 2. 填模型

打开控制台 <http://127.0.0.1:3070> → 左侧「设置」→「大脑（API）」：

| 字段 | 例子 | 说明 |
|---|---|---|
| baseUrl | `https://api.deepseek.com/v1` | OpenAI 兼容接口，结尾一般是 `/v1` |
| apiKey | `sk-...` | 你自己的 Key |
| model | `deepseek-chat` | 支持 function calling 的模型更好用 |

点「保存」，然后回聊天窗说话。

> 填错了她会说"连不上模型"，控制台「日志」里能看到具体状态码（401 = Key 错，402/403 = 余额或权限，503 = 对方忙）。

## 3. 跟她说话

```
你：你在干嘛
她：刚收拾完桌子，在窗边坐着发呆呢。你回来啦？
```

想让她拍照：`你：拍张你现在的样子看看`

## 4. （可选）接 QQ

1. 装 [NapCat](https://github.com/NapNeko/NapCatQQ)（QQ 协议端），记下它的安装路径。
2. 控制台「设置」填：你的 QQ 号（主人号）、小号 QQ 号、NapCat 路径。
3. 控制台「状态」→「立即换一张」→ 手机 QQ 扫码。
4. 登录后 QQ 里就能聊；**只有主人能让她动电脑，群里任何人都不行**。

不接 QQ 也完全能用——浏览器聊天窗就是主界面。

## 5. 出问题了看哪

| 现象 | 看这里 |
|---|---|
| 聊天窗空白/一直"连接中" | 控制台「日志」最后 20 行 |
| 她不理你 | 日志里有没有 `-> reply`；有没有 `HTTP 4xx/5xx` |
| 打不开 3210 | 装 `data\chat-port.txt` 里写的端口（可能是 3211） |
| 想重来 | 删 `data\` 目录（会清掉记忆，先备份） |

实在不行，把 `data\bridge.log` 最后 30 行贴到 Issues。
