# 记忆：她是怎么记住你的

## 记什么

她不是把聊天记录塞进上下文，而是把"关于你的事实"抽出来存成条目：

- **核心**：几乎不会忘（你是谁、你是主人、长期设定）
- **事实**：会随时间变淡（面试在哪天、你喜欢什么、答应过什么事）
- 此外还有：**长期自我**（她自己的近况）、**经验库**（哪种回答被夸/被嫌）、**技能记录**（哪个工具用过、成没成）

## 强度怎么算

每条记忆有个"基础权重"和"当前强度"。强度随时间衰减，被提到、被确认时会回升（类似艾宾浩斯）。控制台「记忆」页里能看到每条现在的强度条。

- 基础权重高的（核心）衰得慢
- 很久没被提到的，会降到很低但不会瞬间消失

## 说错了怎么办

你纠正她的时候，旧说法不会直接删掉，而是标成"已被更正"，不再拿来用；新说法接上去。这样既能改对，也不会把历史抹掉——她在控制台「记忆」里能看出来"这条更正了哪几条"。

## 她不会记混人

记忆按 QQ 号分文件：`data\agent-home\memory\people\<QQ号>.json`。
浏览器聊天窗和 QQ 私聊是**同一个人**（都指向主人的号），所以两边的记忆是同一份；群里别人的话不会被记成你的。

## 手动管

控制台「记忆」页：

- 下拉选号，能看到这个号的每一条记忆（内容 / 基础权重 / 当前强度 / 类型 / 来源）
- 可以手写一条「要记住的事」，比如"他下周三面试"
- 可以删单条；**删整个号的记忆**需要授权码（在「状态」页生成 6 位码，5 分钟有效），防止误删把自己锁在外面

## 备份

控制台的「备份」把记忆、经验库、技能库、配置、聊天记录打包到 `%USERPROFILE%\DSChatBot-backups`，默认留 7 份，每天自动一次。升级覆盖安装不会动记忆。

## 文件

| 路径 | 内容 |
|---|---|
| `data\agent-home\memory\people\<QQ>.json` | 这个人的记忆条目 |
| `data\self-facts.json` | 她自己的长期近况 |
| `data\life.json` | 作息 / 情绪等状态 |
| `data\ledger\` | 工作模式的改动快照与审计 |
