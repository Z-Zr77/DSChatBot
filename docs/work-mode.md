# 允许她动电脑（可选，默认关闭）

她默认**只能聊天**。打开这个开关，她才能在你指定的一个文件夹里读文件、改文件、跑命令。

## 怎么开

控制台 →「设置」→「允许她动电脑」：

1. 勾上开关；
2. 选一个**工作文件夹**（她只能在这里面动手，例如 `D:\我的项目`）；
3. 保存。

> 建议先拿一个不重要的文件夹练手，别一上来就指到桌面或系统目录。

## 打开之后她会做什么

- 你说「把 `readme.txt` 第二行改成新的」，她会先**问你一句**，你同意才改。
- 每次改动都有快照，可以单条撤回，也可以「撤销这次全部改动」。
- 删文件是搬进回收站（`工作文件夹\.trash\`），不是直接抹掉。
- 跑命令有白名单（node / npm / git / python 等），结果截断后给她看。

## 边界（重要）

- **这不是沙箱**。她调 `npm install` 时，那个进程有你的用户权限，能碰到你能碰的所有文件。我们用白名单+路径检查+超时+审批把风险压低，但不能保证"绝对出不去"。
- **只有主人能用**。主人号在「设置」里填；QQ 群里任何人、任何陌生私聊，都不能触发这些操作。
- 默认不联网。要看网页得单独开，而且本机/内网地址一律不抓。
- 改动会记在 `data\ledger\`（授权、快照、审计），可以查。

## 关掉之后

- 她的工具请求一律被拒，回复是"这个我改不了"。
- 已经存在的改动记录还在，仍可恢复。

## 常见问题

**她说"这个位置不允许读"** —— 你想让她看的东西不在工作文件夹里。把那个目录选成工作文件夹，或把文件复制进去。

**她说"跑命令要先进工作模式"** —— 开关没开，或重启后没重开（授权不持久）。

**改坏了怎么办** —— 控制台 →「状态」→ 工作模式卡片里的「本次改动」，逐条「恢复」；或点「撤销这次全部改动」。
